NeuroLog is a lightweight, offline-first floating desktop companion for Windows 10 and 11.

Your thoughts don't always show up at the right time. NeuroLog gives them somewhere to go—so you can capture an idea, clear it from your head, and get back to what you were doing.

## Why NeuroLog?

Your brain shouldn't have to choose between **remembering an idea and staying focused**.

Normal blockers fight your thoughts. NeuroLog remembers them for you—so you can stay focused without the fear of forgetting something creative.

---

## One Small Pill. A Lot of Possibilities.

NeuroLog stays quietly on your desktop until you need it.

From one floating pill, you can jump between tasks, Creative Time, timers, the stopwatch, quick capture, and more—without opening another full-sized app.

## Built for Your Desktop

NeuroLog is designed to stay out of your way while keeping the things that matter close by.

- **Offline-first** — No internet connection required.
- **Floating pill** — Keep NeuroLog accessible without keeping a full window open.
- **Quick capture** — Get thoughts out of your head before they become distractions.
- **Native windows** — Focused tools without one giant application window.
- **Local** — Your data stays on your machine.
- **Windows 10 & 11** — Built for the Windows desktop.

<details>
<summary><strong>Development</strong></summary>

### Requirements

- Node.js
- Rust
- Tauri v2 prerequisites

### Run locally

```bash
npm install
npm run tauri dev
```

For browser preview:

```bash
npm run dev
```

### Production Build

```bash
npm run tauri build
```

Windows installers and release binaries are generated under:

```text
src-tauri/target/release/bundle/
```
